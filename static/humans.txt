  Standards: HTML5, CSS custom properties, progressive enhancement
  Components: none. No framework, no CDN, no webfonts, no analytics scripts,
              no third-party requests of any kind. The site is a static
              generator written in ~200 lines of Node with zero dependencies.
  Typography: system font stacks only — instant first paint, zero layout shift
  Software:   Node 20, a text editor, and a pen

  Every page is readable with JavaScript disabled.
