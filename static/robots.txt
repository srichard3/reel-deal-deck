# ---------------------------------------------------------------------------
# The Reel Deal Deck — robots.txt
#
# Policy: crawl everything. This site is a 60-odd page reference library whose
# entire acquisition strategy is organic search. There is nothing here worth
# hiding from a crawler, and every Disallow is a chance to accidentally
# de-index the Fly-brary. The only rules below strip tracking parameters,
# which create infinite duplicate URLs of pages we want indexed exactly once.
#
# Do NOT add Disallow lines for /flies/ or its facet URLs (/flies/?type=dry).
# Those facets are linked from the footer and are legitimate crawl paths.
#
# Verify after any change: Search Console → Settings → robots.txt report.
# ---------------------------------------------------------------------------

User-agent: *
Allow: /

# Campaign / referral parameters. These duplicate real pages under junk URLs
# and dilute the signal for the canonical version. Canonical tags already
# handle this; these rules stop the crawl budget being spent to find that out.
Disallow: /*?*utm_
Disallow: /*?*gclid=
Disallow: /*?*fbclid=
Disallow: /*?*msclkid=
Disallow: /*?*igshid=
Disallow: /*?*mc_cid=
Disallow: /*?*mc_eid=
Disallow: /*?*_hsenc=
Disallow: /*?*ck_subscriber_id=

# The 404 template is a real route so it can be styled and tested. It is
# marked noindex in its front matter (kept out of sitemap.xml) and served with
# X-Robots-Tag: noindex — see static/_headers.
Disallow: /404/

# ---------------------------------------------------------------------------
# AI crawlers — stated explicitly rather than inherited from `User-agent: *`.
# This is a content-licensing decision. Current position: allow everything.
# The free reference content on this site exists to be found and quoted, and a
# citation inside an AI answer reaches the beginner we are trying to reach.
#
# To withhold the site from model TRAINING while keeping it available for
# assistant SEARCH and live user fetches, change GPTBot, ClaudeBot, CCBot,
# Google-Extended, Applebot-Extended and Bytespider below to `Disallow: /`
# and leave the rest allowed. Do not disallow Googlebot or Bingbot under any
# circumstances — those are the search crawlers, and Google-Extended is a
# separate token that has no effect on Search ranking.
#
# NOTE ON THE TRACKING-PARAMETER RULES ABOVE: a crawler obeys only the most
# specific group that matches it, so the named agents below do NOT inherit the
# `Disallow: /*?*utm_` family from `User-agent: *`. That is accepted rather than
# repeated eleven times: this site never emits a URL carrying those parameters,
# they only arrive on inbound links, and the cost of an assistant crawling a
# tagged duplicate is a little wasted crawl budget. Googlebot and Bingbot are
# NOT named here, so they still match `*` and still get the rules.
# ---------------------------------------------------------------------------
